# JavaScript Warm Up

This project contains introductory Node.js scripts that practice constants,
command-line arguments, loops, recursion, objects, functions, and modules.
Every exercise uses modern JavaScript declarations and prints output with
`console.log(...)` as required by the assignment.

## Exercises

- Basic output and argument handling
- Integer conversion and arithmetic
- Loops for repeated output and squares
- Recursive factorial calculation
- Finding the second-largest argument
- Object mutation and CommonJS exports

Run a script from this directory with:

```bash
./0-javascript_is_amazing.js
```
