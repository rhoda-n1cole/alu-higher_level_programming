# JavaScript Web Scraping

This project practices reading and writing files and consuming HTTP APIs with
Node.js. The scripts use the required `request` module for web requests and
Node's built-in `fs` module for UTF-8 file operations.

## Exercises

- Read a file and report file-system errors
- Write UTF-8 text to a file
- Display HTTP status codes
- Read Star Wars movie data from the SWAPI API
- Count films featuring Wedge Antilles
- Store a webpage response in a file
- Count completed JSONPlaceholder tasks by user

Each script accepts its inputs through command-line arguments and is executable
with the required Node.js shebang.
