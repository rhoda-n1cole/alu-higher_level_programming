# JavaScript Web jQuery

This project practices browser-side JavaScript with the jQuery API. The
scripts update page content, respond to clicks, manipulate classes and lists,
and fetch data from public APIs.

## Exercises

- Change header colors with native DOM and jQuery
- Toggle classes and add list items on click
- Update header text
- Fetch a Star Wars character and movie titles
- Fetch a French greeting after the DOM loads

The scripts are designed for the HTML fixtures provided by the assignment and
use no JavaScript framework other than the required jQuery API.
