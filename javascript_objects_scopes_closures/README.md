# JavaScript Objects, Scopes and Closures

This project practices object-oriented JavaScript with Node.js. It introduces
classes, constructors, inheritance, instance methods, modules, closures, and
array manipulation without external libraries.

## Exercises

- Rectangle classes with validation, printing, rotation, and doubling
- Square classes that inherit from rectangles
- Occurrence counting and manual list reversal
- A stateful logging closure
- A number-base converter closure

All exercise files use the required executable Node.js shebang and CommonJS
module format where a function or class must be imported by another script.
